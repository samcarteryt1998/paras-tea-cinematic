# Paras Tea Cinematic Website

Client-review build for Paras Tea.

This repository implements the approved Paras Tea cinematic homepage using a canvas-based frame-sequence renderer rather than direct MP4 seeking. The build pipeline downloads the approved source media, converts it into frame sequences, and packages the final assets into the deployed site.

Core narrative:
Leaf → Transformation → Golden Tea → Brew → Pour → Doodh Patti → Product Universe → Origin → Contact.

The implementation preserves the approved long-pour section and the locked Scene 03–06 choreography corrections.
